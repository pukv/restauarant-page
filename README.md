# Restaurant Page

A modern restaurant website with dynamic content rendering using JavaScript modules.

## 🚀 Live Demo  
[View Live Site](https://pukv.github.io/restauarant-page/)

## 🛠️ Tech Stack
- HTML5
- CSS3  
- JavaScript ES6 Modules
- Webpack

## ✨ Features
- Dynamic tab-based navigation
- Modular JavaScript architecture
- Responsive restaurant layout
- Separate pages for Home, Menu, and Contact

## 💡 Code Highlights
- ES6 module system
- Webpack bundling
- Dynamic DOM rendering
- Tab-based SPA navigation

## 🎯 Skills Demonstrated
- JavaScript modules
- Build tools (Webpack)
- Single Page Application concepts
- Content rendering patterns
